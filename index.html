    OncoRisk Home

    This is the main dashboard for OncoRisk, a web platform within the Phenome Portal that provides advanced genomic analysis, visualization, and a structured knowledge base to support precision oncology workflows.

    Main Purpose

    OncoRisk combines analysis tools (for running and visualizing genomic pipelines) with a curated oncology knowledge base (variants, diseases, therapies, phenotypes, etc.) so users can move from raw variant data to clinically relevant interpretations.

    Home Dashboard Content

    The Home page (OncoRisk landing view) gives a high-level overview and shortcuts.

    Quick Actions

    • Upload New Analysis: Start a new run of pipeline or variant analysis by uploading data.
    • Browse Knowledge Base: Explore entities (variants, diseases, etc.) through faceted lists.
    • Perform Deep Query: Construct custom queries across the integrated data.
    • Documentation: Open the official documentation (linked from the Help system).

    Basic Step-by-Step Usage

    A minimal workflow using the information exposed on the page looks like this.

    1. Log in and go to Home (OncoRisk dashboard).
    2. Click “Upload New Analysis” to load your genomic data (e.g., MAF) and start Pipeline Analysis.
    3. Use Pipeline Analysis to generate single‑ or multi‑sample reports, then review summary and variant‑level findings.
    4. Open the Knowledge Base sections (Variants, Diseases, Therapies, Assertions, Evidence) to inspect how observed variants are annotated and what therapies or phenotypes are linked.
    5. Use Deep Query or Network Tools to explore relationships among variants, diseases, therapies, and phenotypes across the full dataset.
    6. If needed, configure Settings (API connections, user access) and consult the Help document for detailed, page‑by‑page instructions and troubleshooting.
