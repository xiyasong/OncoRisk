# Analysis Tools

OncoRisk provides a suite of analysis tools to explore and interpret genomic data.

## Deep Query
Interactive querying of patients, variants, genes, or other entities across the knowledge base.

## Pipeline Analysis
Upload and process genomic result files (e.g., MAF/VCF) and generate reports.

## Network Tools
Visualization of gene-gene, variant-pathway, or phenotype networks. For a detailed guide, see the [Network Tools Tutorial](network_tools.md).

## MAF Tools
Utilities dedicated to handling Mutation Annotation Format files, such as filtering and summarization.

## Pan Cancer Visual
Cross-cancer visualizations to compare signals across multiple tumor types.
